# Beauty 1010: QR-сторінка зі знижкою 10 %

Мобільна сторінка для салону **Beauty 1010** (Kleeblattgasse 11, 1010 Wien). Клієнт сканує QR-код у салоні й бачить привітання та подарунковий купон на 10 %. Звідти він одразу переходить на запис у Treatwell.

- **Жива адреса:** https://zwolfros-debug.github.io/beauty1010/
- Мова сторінки для клієнтів: **лише німецька**.
- Без cookies, аналітики, форм і збору даних. Шрифти лежать на самому сайті (без Google Fonts).

## Що є в папці

| Шлях | Що це |
|---|---|
| `src/config/brand.ts` | **Усі налаштування в одному місці:** знижка, тексти купона, умови, посилання, адреса, кольори, Impressum |
| `src/App.tsx` | Сторінка: вступ, купон, запис, салон, фінал |
| `src/components/Coupon.tsx` | Купон-картка |
| `src/components/Logo.tsx` | Логотип (векторне відтворення, див. «Що ще потрібно») |
| `src/lib/couponImage.ts` | «Gutschein speichern»: малює PNG купона прямо на телефоні |
| `public/qr/` | QR-код: `beauty1010-qr.svg`, `beauty1010-qr.png` (4096 px), `beauty1010-qr-black.png` |
| `print/` | Друк: A5 і A6 у PDF з виступом під обріз 3 мм, PNG-прев'ю 300 dpi, квадрат 1080×1080 для соцмереж |
| `BRAND_GUIDELINES.md` | Фірмовий стиль: кольори, шрифти, логотип, фото |
| `scripts/` | Генерація QR, друку й фото, тести |

## Як змінити знижку або умови

Усе змінюється у файлі `src/config/brand.ts`, блок `offer`:

```ts
discountPercent: 10,          // 15 → скрізь стане «15 %»
code: null,                   // 'BEAUTY10' → на купоні з'явиться код
validUntil: null,             // '31.12.2026' → «Gültig bis 31.12.2026»
conditions: [],               // ['Nicht mit anderen Aktionen kombinierbar.']
```

`null` або порожній список означає, що на сторінці нічого не показується. Нічого не вигадано.

Після зміни:
1. `npm run print`: перемалювати друк і картинку для соцмереж, якщо змінилась знижка.
2. Зробити `git commit` і `git push`. Сайт оновиться сам приблизно за 1 хвилину (GitHub Actions).

**QR-код при цьому НЕ змінюється** і роздруковані картки продовжують працювати.

## Публікація (розгортання)

Хостинг: **GitHub Pages**, безкоштовно й постійно. Кожен `git push` у гілку `main` збирає й публікує сайт (`.github/workflows/deploy.yml`).

Чому GitHub Pages: акаунт GitHub уже є, нічого не треба реєструвати чи оплачувати, HTTPS є, адреса стабільна. Порівняння варіантів:
- Netlify / Vercel / Cloudflare Pages: теж безкоштовні й добрі, але потребують окремого акаунта.
- Cloudflare Pages найкраще підходить, якщо згодом з'явиться власний домен у Cloudflare.

### Власний домен (якщо колись буде, наприклад `beauty1010.at`)
1. У налаштуваннях репозиторію відкрити GitHub → Settings → Pages → Custom domain і вписати домен.
2. У реєстратора домену додати запис CNAME `www` → `zwolfros-debug.github.io`.
3. У `vite.config.ts` змінити `base` на `'/'`, а в `brand.ts` змінити `publicUrl`.
4. ⚠️ Новий домен означає **новий QR-код** (`npm run qr && npm run print`), і картки треба передрукувати. Щоб старі картки працювали й далі, сторінку на github.io треба лишити як переадресацію.

## Перевірки

```bash
npm run qr          # створити QR з publicUrl
npm run test:qr     # прочитати QR назад і перевірити адресу
npm run print       # A5, A6, квадрат, іконки, OG-картинка
node scripts/shoot.mjs           # скріншоти iPhone/Android/Desktop + помилки консолі
node scripts/test-functions.mjs  # кнопки, купон, збереження, Impressum
```

## Що ще потрібно від салону (до друку)

1. **Оригінальний файл логотипа** (SVG/PDF/AI). Зараз це точне векторне відтворення з аватарки Instagram розміром 150 px.
2. **Дані для Impressum.** В Австрії це обов'язково для сайту бізнесу (§ 5 ECG, § 25 MedienG): назва фірми або власник, e-mail чи телефон, UID, Firmenbuch, Gewerbebehörde, палата. Їх вписують у `legal` у `brand.ts`.
3. **Умови купона:** чи поєднується знижка з акціями Treatwell («Spare bis zu 10 %»), чи є термін дії, чи одна знижка на людину.
4. **Дозвіл на фото.** Зараз використано 3 фото зі сторінки салону на Treatwell.
